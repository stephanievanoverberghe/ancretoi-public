# `src/content/copy`

Ce dossier accueillera les textes courts et copy transverses.

À mettre ici :

- micro-copy ;
- messages publics ;
- libellés stables ;
- textes de récupération.

À ne pas mettre ici :

- logique métier ;
- appels API ;
- contenus éditables DB.

Les déplacements se feront PR par PR en gardant le build stable. Les routes visibles restent françaises. RESET-7 reste en 7 journées, sans matin/midi/soir.
