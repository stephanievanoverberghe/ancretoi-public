# `src/content/programmes`

Ce dossier contient les contenus statiques lies aux programmes quand ils servent de reference ou de seed canonique.

A mettre ici :

- textes de reference ;
- contenus de seed ;
- copy programme temporaire.

A ne pas mettre ici :

- source DB runtime ;
- logique Prisma ;
- acces base de donnees ;
- routes.

Prisma + Neon est la source applicative. RESET-7 reste en 7 journees, sans matin/midi/soir.
