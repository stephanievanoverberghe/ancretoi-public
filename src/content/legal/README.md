# `src/content/legal`

Ce dossier accueillera les contenus légaux statiques.

À mettre ici :

- mentions légales ;
- conditions générales ;
- confidentialité ;
- cookies.

À ne pas mettre ici :

- logique de consentement runtime ;
- analytics ;
- composants interactifs.

Les routes visibles restent françaises. Les déplacements se feront PR par PR en gardant le build stable. RESET-7 reste en 7 journées, sans matin/midi/soir.
