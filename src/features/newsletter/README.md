# `src/features/newsletter`

Ce dossier contient les composants et helpers metier de newsletter cote UI.

A mettre ici :

- formulaires newsletter ;
- composants d'administration newsletter ;
- types et validations de formulaires cote UI.

A ne pas mettre ici :

- integration email serveur ;
- acces base de donnees direct ;
- route handlers newsletter.

Les services serveur newsletter vivent dans `src/server/newsletter`.
