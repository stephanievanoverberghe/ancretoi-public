# `src/features/public/inspirations`

Ce dossier contient les composants, types et helpers metier des inspirations publiques.

A mettre ici :

- composants publics des inspirations ;
- galeries et heros d'inspirations ;
- types et helpers UI specifiques aux inspirations.

A ne pas mettre ici :

- acces direct a la base de donnees ;
- route handlers Next.js ;
- services serveur partages ;
- composants UI generiques ;
- logique d'administration hors PR dediee.

Les routes visibles restent francaises. RESET-7 reste hors perimetre ici et garde 7 journees sans matin/midi/soir.
