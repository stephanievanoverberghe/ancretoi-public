# `src/features/public/blog`

Ce dossier contient les composants, types et helpers metier du blog public.

A mettre ici :

- composants publics du blog ;
- composants de lecture d'article ;
- types de domaine blog ;
- helpers UI blog.

A ne pas mettre ici :

- route handlers Next.js ;
- services serveur CRUD ;
- acces base de donnees direct ;
- composants UI generiques ;
- logique d'administration hors PR dediee.

Les routes visibles restent francaises. RESET-7 reste hors perimetre ici et garde 7 journees sans matin/midi/soir.
