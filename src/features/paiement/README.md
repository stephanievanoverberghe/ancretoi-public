# `src/features/paiement`

Feature cible pour les composants côté paiement.

À mettre ici :

- composants de confirmation paiement ;
- états checkout côté UI ;
- messages de récupération.

À ne pas mettre ici :

- webhook Stripe ;
- création de sessions checkout ;
- accès DB direct ;
- prix ou catalogue.

Les déplacements se feront PR par PR. Stripe reste hors périmètre sauf demande explicite. Les routes visibles restent françaises. RESET-7 reste en 7 journées, sans matin/midi/soir.
