# `src/app/(public)`

Route group cible pour les routes publiques. Le segment `(public)` organise le code mais n'apparaît pas dans l'URL.

À mettre ici plus tard :

- accueil ;
- programmes ;
- méthode ;
- témoignages ;
- blog ;
- inspirations ;
- aide ;
- contact ;
- pages légales.

À ne pas mettre ici :

- routes auth ;
- espace apprenant ;
- administration ;
- logique métier lourde.

Les migrations de routes se feront PR par PR. Les routes visibles restent françaises et le build doit rester stable. RESET-7 reste en 7 journées, sans matin/midi/soir.
