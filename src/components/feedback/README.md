# `src/components/feedback`

Ce dossier accueillera les composants de feedback transverses.

À mettre ici :

- états empty/loading/error/success ;
- alertes génériques ;
- messages de validation ;
- toasts si une librairie est ajoutée plus tard.

À ne pas mettre ici :

- messages métier propres à RESET-7 ou à l'admin ;
- logique API ;
- accès serveur.

Les extractions se feront PR par PR en gardant le build stable. Les routes visibles restent françaises. RESET-7 reste en 7 journées, sans matin/midi/soir.
