# `src/components/common`

Ce dossier accueillera les petits composants transverses non métier.

À mettre ici :

- wrappers simples ;
- helpers visuels partagés ;
- composants sans logique domaine.

À ne pas mettre ici :

- composants UI de base, qui vont dans `src/components/ui` ;
- composants métier, qui vont dans `src/features` ;
- shells de navigation, qui vont dans `src/components/layout`.

Les déplacements se feront PR par PR en gardant le build stable. Les routes visibles restent françaises. RESET-7 reste en 7 journées, sans matin/midi/soir.
