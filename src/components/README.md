# `src/components`

Ce dossier regroupe les composants transverses non liés à une feature précise.

À mettre ici :

- composants UI génériques ;
- composants layout ;
- feedbacks transverses ;
- petits composants communs.

À ne pas mettre ici :

- logique métier programmes, apprentissage, journal ou admin ;
- appels API ;
- accès DB ;
- composants liés à une route spécifique.

Les déplacements se feront PR par PR en gardant le build stable. Les routes visibles restent françaises. RESET-7 reste en 7 journées, sans matin/midi/soir.
