# `src/server/journal`

Service serveur cible pour le journal.

À mettre ici :

- sauvegarde des réponses ;
- lecture des journaux ;
- règles de validation ;
- préparation des données de bilan.

À ne pas mettre ici :

- composants de formulaire ;
- styles ;
- logique client.

Les déplacements se feront PR par PR en gardant le build stable. Les routes visibles restent françaises. RESET-7 reste en 7 journées, sans matin/midi/soir.
