# `src/server/inspirations`

Service serveur cible pour les inspirations.

À mettre ici :

- lecture inspirations ;
- règles de publication ;
- services admin inspirations ;
- mappings de contenu.

À ne pas mettre ici :

- composants React ;
- styles ;
- route handlers volumineux.

Les déplacements se feront PR par PR en gardant le build stable. Les routes visibles restent françaises. RESET-7 reste en 7 journées, sans matin/midi/soir.
