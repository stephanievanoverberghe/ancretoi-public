# `src/server/blog`

Services serveur du blog.

A mettre ici :

- lecture blog ;
- regles de publication ;
- services admin blog ;
- mappings lies aux articles.

A ne pas mettre ici :

- composants React ;
- styles ;
- routes visibles.

`posts.service.ts` contient le service articles admin existant.
`public-posts.service.ts` contient la lecture publique utilisee par `/api/blog`.

Les routes visibles restent francaises. RESET-7 reste en 7 journees, sans matin/midi/soir.
