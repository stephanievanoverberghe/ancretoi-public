# `src/server/exports`

Service serveur cible pour les exports.

À mettre ici :

- exports PDF ;
- exports JSON ;
- préparation des carnets, bilans et données personnelles.

À ne pas mettre ici :

- composants React ;
- styles ;
- logique de journal côté client.

Les déplacements se feront PR par PR en gardant le build stable. Les routes visibles restent françaises. RESET-7 reste en 7 journées, sans matin/midi/soir.
