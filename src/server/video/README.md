# `src/server/video`

Service serveur cible pour la vidéo et les assets média.

À mettre ici :

- métadonnées vidéo ;
- VTT, chapitres, transcripts ;
- futures intégrations média ;
- services d'assets.

À ne pas mettre ici :

- player React ;
- upload provider sans PR dédiée ;
- DRM ou refonte média hors décision explicite.

Les déplacements se feront PR par PR en gardant le build stable. Les routes visibles restent françaises. RESET-7 reste en 7 journées, sans matin/midi/soir.
